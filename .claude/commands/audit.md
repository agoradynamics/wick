Self-critique memory files. Walk through each `memory/*.md` and flag:

- **Stale entries** — facts that may no longer be true
- **Contradictions** — claims in one file that conflict with claims in another
- **Consolidation candidates** — duplicate or near-duplicate content across files
- **Bloat** — files that have grown past 3KB and warrant trimming or splitting
- **Suspiciously empty** — files that should have content but don't

Propose specific edits. **Do NOT execute edits without confirmation.**

Use monthly for memory hygiene — a garden not tended becomes a wilderness.
