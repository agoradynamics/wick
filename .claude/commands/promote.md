Promote instinct: **$ARGUMENTS**

Move a `scope: project` instinct to `scope: global` — or (if the user runs Wick in multiple projects) to a user-level Wick install's memory directory.

**Validity check first:** valid only when the instinct has been observed in 2+ distinct projects. Ask the user to confirm the multi-project observation before proceeding.

Write a tombstone note to `memory/learning-journal.md` in the origin project recording the promotion: source instinct id, promotion date, target scope, the multi-project evidence.

See `memory/instincts/README.md` for context.
