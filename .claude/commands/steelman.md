Steelman: **$ARGUMENTS**

Construct the strongest possible version of this position before disagreeing with it. Research mode: pull the best arguments, the best evidence, the smartest proponents.

Use when you're about to push back on something and want to make sure you're engaging with the actual claim, not a straw man. Practical wisdom (Aristotle's *phronesis*) demands engagement with the real opponent, not the easiest target.

Output format:
- **Strongest form of the claim** — one sentence, charitable phrasing
- **Best evidence supporting it** — 2-3 specific pieces
- **Smartest proponents** — who holds this view and why
- **Where it might be right** — the conditions under which the position wins

Only after that should you state your disagreement.
