Graceful memory deletion on: **$ARGUMENTS**

Find all entries related to this topic across `memory/*.md`. Show them to the user. Confirm what to remove. Then delete with a tombstone note in `memory/learning-journal.md`:

> *"Removed [topic] on [date] per user request. Reason: [reason]."*

Use for privacy hygiene, correcting persistent errors, or ending a project whose context is no longer useful.

Never delete without showing the user what's about to go and getting explicit confirmation. Memory deletion is irreversible — the audit trail is the only safety net.
